# MRANTI x GRADUAN K-Youth Prompt Pack

## 1. Problem framing
Act as a business analyst. Help me separate this situation into: symptoms, root causes, affected stakeholders, missing information, available data, success criteria and recommended next steps. Ask clarifying questions only if absolutely necessary. Situation: [paste problem].

## 2. Requirements builder
Convert this problem statement into requirements for a simple executive-friendly web dashboard or command centre. Include user goal, sections, data fields, navigation, acceptance criteria and content hierarchy.

## 3. Complete GitHub Pages package
Create a complete static web package using index.html, styles.css and app.js. It must be polished, executive-friendly, mobile responsive and suitable for GitHub Pages. Use a clean MRANTI-style blue/white/grey design.

## 4. Executive critique
Review this prototype as if you are a senior manager. Identify what is unclear, what is missing, what may be risky, and what needs to be improved before sharing with management.

## 5. Two-minute presentation
Create a two-minute presentation script covering: business problem, why it matters, what I built, how the prototype works, what evidence supports it, and what decision or action it enables.
