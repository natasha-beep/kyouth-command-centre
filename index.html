01What management approves

Four starting challenge areas, named sponsors, safe data/material access, and permission to use GitHub Pages for prototypes.

02How progress is seen

Working links, sponsor demos, validation findings and a final management showcase — not attendance records alone.

Four scoped problems, four live prototypes, user validation, source notes, handover packages and final recommendations.
