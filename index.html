01Create repo

Name it clearly, e.g. kyouth-prototype-energy.

02Add files

03Enable Pages

Settings → Pages → Deploy from branch → main / root.

04Test live link

Open the published link, fix broken assets, and capture feedback.

POSITIONING

What this programme is

A practical graduate activation programme where each participant learns by producing visible work: problem statements, AI-assisted prototypes, GitHub Pages deployments and final business readouts.

NOT THIS

What this programme avoids

It is not slide-heavy classroom training, generic motivation, or AI theory. Every learning block ends with a tangible output.

ASK FROM BOSS

What needs approval

Confirm the first 4 division challenge areas, sponsors, expected deliverables and permission for graduates to use GitHub Pages as a working prototype environment.

SUCCESS MEASURE

How we know it worked

Each graduate delivers a working link, a clear business story, and evidence that the output was tested with a real internal user or sponsor.
