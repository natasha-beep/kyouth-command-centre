Graduates & Capability Standard

The command centre tracks the delivery standard without hard-coding a candidate list that may change after selection.

Cohort standard

Four graduates. Placement is based on observed delivery evidence, not CV alone. Every graduate must demonstrate problem framing, data trust, technical judgement, automation reliability, stakeholder usefulness, documentation and independent verification.

Expected capabilities by 25 Sep

  • Diagnose messy business/data problems.
  • Build a trustworthy analytical foundation.
  • Create decision-ready Power BI / web output.
  • Automate a repeatable process with visible failure handling.
  • Use AI deliberately and verify its output.
  • Ship, document, hand over and present.

Project allocation profiles

  • Programme / transformation / analytics automation.
  • Engineering / integration / data platform.
  • AI / innovation / data product.
  • Operations / performance / management reporting.
