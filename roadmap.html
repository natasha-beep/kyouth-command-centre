37-Day Roadmap

One continuous build: diagnose → build trusted data → automate → ship → solve a division problem → validate → hand over.

01 · 20–23 Aug

Activate & Diagnose

Problem framing, baseline, Power Query and reproducibility.

Exit evidence: Working baseline + evidence of current capability.

02 · 24–28 Aug

Build Trusted Data

Snowflake foundation, Power BI, reliable pipeline, AI QA, integration challenge.

Exit evidence: Trusted data + management view + reliability evidence.

03 · 29 Aug–4 Sep

Automate & Ship

Documentation, automation architecture, n8n + AI, capstone, security, placement.

Exit evidence: End-to-end product + automation + safe publication.

04 · 5–9 Sep

Discover Division Problem

Research, rehearsal, sponsor discovery, success metrics and data contract.

Exit evidence: Sponsor-validated problem + acceptance tests.

05 · 10–21 Sep

Build & Review

Data, interface, test backlog, sponsor review, automation, Friday demo, final build.

Exit evidence: Working division solution + sponsor feedback.

06 · 22–25 Sep

Validate & Handover

User validation, production readiness, final presentation, 30-day mission.

Exit evidence: Accepted handover + management ask + continuation mission.

Weekly operating rhythm

Monday: outcome and sprint plan. Wednesday: working prototype / sponsor check. Friday: demo, evidence and backlog. On training days, no lecture block exceeds 20 minutes; every major block produces an artifact.
