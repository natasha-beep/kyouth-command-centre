CORE MATERIAL

AI Prompt Pack

1 · Problem framing

Act as a business analyst. Separate this situation into symptoms, root causes, affected stakeholders, available evidence, missing information, success criteria and recommended next steps. Situation: [paste problem].

2 · Requirements builder

Convert this business problem into requirements for an executive-friendly web dashboard or command centre. Include user goal, sections, data fields, navigation, acceptance criteria and content hierarchy.

3 · Complete web package

Create a complete static web package using index.html, styles.css and app.js. It must be polished, mobile responsive and suitable for GitHub Pages. Keep content evidence-based and easy to update.

4 · Executive critique

Review this prototype as a senior manager. Identify what is unclear, missing, unsupported, risky or difficult to act on. Propose the highest-value fixes.

5 · Two-minute story

Create a two-minute explanation covering the business problem, why it matters, what I built, how it works, what evidence supports it and what decision/action it enables.
