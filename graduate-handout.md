# Graduate Handout — K-Youth Activation Lab

## Your mission
You will learn how to take a business problem, use AI to structure it, build a working web prototype, deploy it using GitHub Pages, and explain the business value clearly.

## What you must produce
- A clear problem statement
- A requirement brief
- A prototype web package
- A live GitHub Pages link
- A two-minute explanation of your output

## Rule
Do not just accept AI output. Review it, challenge it, improve it and make it specific to the business problem.
