# MRANTI x GRADUAN K-Youth Command Centre

Ready-to-run GitHub Pages package for the MRANTI x GRADUAN K-Youth Development Programme 2026.

## What is inside
- `index.html` — main command centre
- `styles.css` — GasMY-inspired MRANTI styling
- `app.js` — navigation and data rendering
- `data/programme.js` — calendar, roadmap, runlist, labs and project tracks
- `prompts/prompt_pack.md` — graduate AI prompt pack
- `facilitator-runbook.md` — backup facilitator notes
- `graduate-handout.md` — graduate-facing guide
- `.nojekyll` — required for clean GitHub Pages publishing
- `brief_deck/` — boss/team briefing deck

## Deploy to GitHub Pages
1. Create a new repository.
2. Upload all files in this folder to the repository root.
3. Make sure `.nojekyll` is included.
4. Go to Settings → Pages.
5. Select Deploy from branch → `main` → `/root`.
6. Open the published GitHub Pages URL.
