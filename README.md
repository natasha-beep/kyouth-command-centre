# MRANTI x GRADUAN K-Youth Command Centre 2026

This repository is the operating hub for the programme. The website is intentionally organised around **date → agenda → material → output** so the internal team can run the programme without searching through separate folders or decks.

## What the website contains

- Full roadmap from 13 August to 2 October 2026
- All scheduled programme touchpoints
- A Day Pack for every scheduled date
- Exact agenda and expected outputs for each session
- Direct links to the material required for that day
- Materials Library for quick lookup
- One-page Team / Boss Brief

## GitHub Pages

Upload the **contents of this folder** to the root of the repository so `index.html` is visible on the repository home page.

Then enable:

`Settings → Pages → Deploy from a branch → main → / (root)`

## Most important file to edit

`data/programme.js`

Edit this one file if dates, session titles, owners, agenda blocks or linked materials change. The Command Centre updates automatically from that data.

## Main folders

- `materials/` — printable/openable programme materials
- `starter_repo/` — simple prototype starting files for the Activation Lab
- `brief_deck/` — concise management briefing deck
- `data/programme.js` — programme calendar and Day Pack content

## Programme design principle

Every meaningful programme touchpoint should end with a visible output: problem definition, requirement brief, working link, feedback backlog, validation evidence, final solution or handover.
