Trainer / facilitator control notes

Facilitation posture: demonstrate only enough to unblock the next decision. Do not take over the keyboard. Ask for evidence at every checkpoint.

  • Check that the graduate can explain why the chosen tool/pattern fits the problem.
  • Reject outputs that hide unresolved exceptions or unverifiable numbers.
  • Require a working artifact or evidence before marking the day complete.
  • For public GitHub work, use synthetic/sanitised data only.

⚙ Exercise / Activity

Manual Work → Automation Blueprint

Every reporting cycle an analyst checks portfolio exceptions, identifies follow-up cases, prepares a management summary and sends an update. The build starts tomorrow; today is architecture.

  1. Map the current manual steps as Input → Check → Decision → Action → Record.
  2. Separate deterministic logic from narrative/AI work.
  3. Identify where a human approval is required.
  4. Define the failure path for missing data, invalid totals and failed notification.
  5. Write the final run log fields needed for auditability.
