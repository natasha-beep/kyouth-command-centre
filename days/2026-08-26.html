Trainer / facilitator control notes

Facilitation posture: demonstrate only enough to unblock the next decision. Do not take over the keyboard. Ask for evidence at every checkpoint.

  • Check that the graduate can explain why the chosen tool/pattern fits the problem.
  • Reject outputs that hide unresolved exceptions or unverifiable numbers.
  • Require a working artifact or evidence before marking the day complete.
  • For public GitHub work, use synthetic/sanitised data only.

⚙ Exercise / Activity

Mission 03: Make the Data Run Without You

New funding and milestone records arrive each reporting cycle. A manual rerun is slow and can duplicate rows or refresh trusted KPIs despite bad input.

  1. Implement a repeatable ingest/merge pattern for new records.
  2. Log source, accepted and quarantined row counts.
  3. Inject A1018 and block it from trusted KPIs because the company is unmatched and disbursed exceeds approved.
  4. Re-send A1006 and prove the pipeline updates/merges rather than duplicates.
  5. Expose run timestamp, run status and recovery notes.
  6. Demonstrate one failure and recovery path.
Required deliverables
Repeatable pipeline logic
Run log / status evidence
Quarantine evidence
