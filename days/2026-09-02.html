Trainer / facilitator control notes

Facilitation posture: demonstrate only enough to unblock the next decision. Do not take over the keyboard. Ask for evidence at every checkpoint.

  • Check that the graduate can explain why the chosen tool/pattern fits the problem.
  • Reject outputs that hide unresolved exceptions or unverifiable numbers.
  • Require a working artifact or evidence before marking the day complete.
  • For public GitHub work, use synthetic/sanitised data only.

⚙ Exercise / Activity

Capstone: Portfolio Decision Product

The backend is only useful if a stakeholder can understand, trust and act on it. Graduates choose the strongest delivery method—GitHub Pages, Power BI or equivalent—and must show the full chain from source to action.

  1. State stakeholder, decision and success criterion.
  2. Use the trusted data layer and include visible exceptions.
  3. Integrate at least one automated process or automation evidence.
  4. Build and deploy/publish the management interface using synthetic data only.
  5. Run the security/publication checklist.
  6. Deliver a five-minute management pitch and answer assessor questions.
