FAQ

Operational answers for trainers, graduates and the programme team.

Is the dataset real MRANTI data?

No. The exercise datasets are synthetic and deliberately imperfect. They model MRANTI-relevant operational patterns but must not be presented as production MRANTI records.

Do graduates receive the trainer answer key?

No. The answer key and failure injections are facilitator controls and should only be opened at the relevant checkpoint.

What if Snowflake is unavailable?

Run the same layer and quality logic in DuckDB, SQLite or Python/pandas. The assessed capability is engineering judgement, not tenant access.

What if n8n credentials are unavailable?

Use Manual Trigger, Set, Code and IF/Switch nodes to prove the workflow and log external actions rather than sending them. Document the production credential points.

Can GitHub Pages contain MRANTI data?

Use synthetic or explicitly sanitised data only. Never publish credentials, tokens, internal URLs or personal data.

Is this meant to be lecture-led?

No. Trainer micro-demos are short. The dominant mode is build, test, review and improve.

How are division projects chosen?

The four prepared tracks are starting archetypes. The division sponsor validates the real workflow, decision and acceptance criteria during discovery.

What counts as completion?

A working artifact plus evidence: validation, failure handling, documentation and a clear stakeholder action. Attendance alone is not completion.
