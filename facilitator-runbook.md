# Facilitator Runbook — 20 August 2026

Use `index.html` as the primary command centre. Do not facilitate from this markdown file unless you need a printable backup.

## Operating rule
Every 30–45 minutes must produce a tangible output: a problem statement, prompt result, requirement brief, local prototype, live GitHub Pages link or feedback backlog.

## Intake day outputs
1. Individual problem note
2. One-page problem statement
3. Prototype requirement brief
4. Local HTML/CSS/JS prototype
5. Live GitHub Pages link
6. Mini showcase feedback list
7. Assigned division project track

## Facilitation posture
Keep the session active. Demonstrate only enough to unblock the task, then let graduates build. The goal is to produce working outputs, not to explain every theory behind AI or web development.
