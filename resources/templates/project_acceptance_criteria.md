# Project Acceptance Criteria

A project is accepted only when all of the following are demonstrated:
1. Stakeholder and decision are stated in one sentence.
2. Inputs and owners are documented.
3. Data-quality / validation rules are explicit.
4. Working solution can be reproduced by another person.
5. Failure or exception path is visible.
6. Management output contains an action, not charts alone.
7. README explains operation, assumptions, limitations and next action.
8. Public outputs contain synthetic/sanitised data only.
