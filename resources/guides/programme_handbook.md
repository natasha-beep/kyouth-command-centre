# MRANTI x GRADUAN K-Youth Development Programme 2026 — Programme Handbook

## Delivery model
The programme is a hands-on delivery sprint. The operating sequence is **Diagnose → Build trusted data → Visualise decisions → Make pipelines repeatable → Automate manual work → Ship → Validate → Handover**.

## Non-negotiables
1. Problem first. Tool second.
2. No lecture block longer than 20 minutes.
3. Every major day ends with a tangible output.
4. Synthetic or sanitised data only in public GitHub demos.
5. AI output must be verified; deterministic calculations remain deterministic.
6. Data-quality issues are surfaced, never silently deleted.
7. Another person must be able to understand and operate the final output.

## Core stack
ChatGPT / approved AI tools, SQL, Snowflake or equivalent local engine, Power BI, n8n, GitHub and GitHub Pages.

## Core synthetic scenario
Management needs a reliable view of company participation, funding, milestones, exceptions and follow-up actions. Source files are deliberately inconsistent so graduates must establish trusted definitions before automating or visualising.
