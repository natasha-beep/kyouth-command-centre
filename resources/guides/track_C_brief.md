# Track C — Commercialisation Pipeline Control

## Prepared problem statement
Commercialisation opportunities need a consistent stage, next action and evidence trail. Build a management pipeline view that flags stalled cases, missing next actions, old updates and ownership gaps.

## Dataset
`resources/data/division_tracks/track_C_commercialisation_pipeline.csv`

## Required solution
- Reproducible input transformation.
- Clear decision rules and exceptions.
- At least one automated step.
- Management-facing interface/report.
- README / operating notes.
- Demonstrated failure or exception path.

## Business-value test
Show which manual step is removed, what risk becomes visible, and what management can act on faster.
