# Security & Publication Checklist

Before publishing any GitHub Pages prototype:
- Use synthetic or explicitly sanitised data only.
- Remove credentials, tokens, connection strings and secrets.
- Remove internal-only URLs and hostnames.
- Remove personal data and sensitive contact details.
- Verify every KPI against the trusted data layer.
- Label synthetic data clearly.
- Include methodology / assumptions.
- Check mobile rendering and accessibility.
- Confirm the repository contains no hidden answer key if the graduate-facing URL will be shared.
