# Track A — Submission & Compliance Checker

## Prepared problem statement
Manual first-pass review of submissions can be slow and inconsistent. Build a structured checker that ingests a synthetic submission register and evidence indicators, classifies each requirement as Complete / Partial / Missing / Unable to Verify, and produces an executive exception summary.

## Dataset
`resources/data/division_tracks/track_A_submission_checker.csv`

## Required solution
- Reproducible input transformation.
- Clear decision rules and exceptions.
- At least one automated step.
- Management-facing interface/report.
- README / operating notes.
- Demonstrated failure or exception path.

## Business-value test
Show which manual step is removed, what risk becomes visible, and what management can act on faster.
