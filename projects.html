Division Projects — Phase 2

Four prepared MRANTI-relevant project archetypes. The sponsor validates the real workflow; the starter problems and datasets are ready.

TRACK A

Submission & Compliance Checker

Manual first-pass review of submissions can be slow and inconsistent. Build a structured checker that ingests a synthetic submission register and evidence indicators, classifies each requirement as Complete / Partial / Missing / Unable to Verify, and produces an executive exception summary.

Open track command page →
TRACK B

Partner Follow-up Automation

Partner follow-up can become fragmented across notes, messages and spreadsheets. Build a controlled follow-up queue with owner, next action, due date, priority and escalation logic; automate a management digest without inventing partner facts.

Open track command page →
TRACK C

Commercialisation Pipeline Control

Commercialisation opportunities need a consistent stage, next action and evidence trail. Build a management pipeline view that flags stalled cases, missing next actions, old updates and ownership gaps.

Open track command page →
TRACK D

Utilities & Facilities Exception Monitor

Utility and facility usage records require repeated comparison to find abnormal cost/usage movements. Build an exception monitor that identifies material changes, records investigation ownership and produces a monthly action queue.
